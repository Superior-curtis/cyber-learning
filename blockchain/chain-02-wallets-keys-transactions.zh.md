# 錢包、金鑰與交易

> 📅 2026-08-05 · 核心概念
> 區塊鏈沒有「帳號密碼」——你的身分就是一對金鑰。錢包不是「放錢的地方」，而是「保管金鑰的地方」。這篇拆開地址、簽章與交易，並解釋為什麼私鑰外洩等於資產全失。

---

`chain-01-blockchain-basics` 講了帳本是怎麼鎖死的。但你可能還有個更貼身的疑問：**使用者這一側，到底怎麼「登入」一個區塊鏈？**

答案可能讓你意外：**區塊鏈沒有帳號密碼。你的身分，就是一對金鑰。**

## 錢包不是錢包

先拆一個最大誤解：**「錢包」不是放錢的地方，而是「保管金鑰」的地方。**

* 你的資產（幣、NFT）其實都記在鏈上的帳本裡，從來不在你的手機裡。
* 「錢包」只是保管「能動用那些資產的金鑰」，並幫你簽名。

把錢包想成**一串鑰匙圈**，而不是一個皮夾——弄丟鑰匙圈，不是「皮夾裡的錢沒了」，而是「再也開不了保險庫」。

## 地址與金鑰

還記得 `crypto-03-asymmetric-crypto` 的非對稱加密嗎？區塊鏈把它直接用上了：

| 金鑰 | 作用 | 可以公開嗎 |
|---|---|---|
| 私鑰 | 簽名、動用資產 | **絕不** |
| 公鑰 | 驗證簽名 | 可以 |
| 地址 | 從公鑰推導出的「收件地址」 | 可以 |

登入與授權的邏輯是：**你擁有某個地址 = 你持有那對應的私鑰。** 這正是 `blue-07-iam-zero-trust` 講的「身分」——在鏈上，身分就是「能證明你持有私鑰」。

## 交易與簽章

發一筆交易，本質上是**用私鑰簽一份「我轉帳 X 給某地址」的聲明**：

```
# 概念示意：一筆交易的核心欄位
{ from: 0x我的地址, to: 0x對方地址, amount: 1.0, nonce: 5 }
簽名 = sign(交易內容, 我的私鑰)
```

任何人拿到「交易內容 + 簽名 + 我的公鑰」，都能驗證：**這真的是持鑰人同意發出的。** 驗證通過，礦工/驗證者就把它寫進下一個區塊。簽章的概念，與 `crypto-03-asymmetric-crypto` 講的數位簽章完全一致。

> 鏈上沒有「忘記密碼」。 傳統系統可以「重置密碼」，區塊鏈不行——私鑰就是一切。備份私鑰（助記詞）等同於備份你的身分與資產。

## 私鑰外洩 = 資產全失

這裡是資安的重點。鏈上資產的規則是：

* **誰持有私鑰，誰就能動用資產。** 鏈上不認識「你本人」，只認「私鑰」。
* 私鑰被偷，攻擊者直接把資產轉走，**無法追回、無法撤銷**——交易一旦上鏈就是永久。
* 所以鏈上攻擊的頭號目標，從來不是「駭進鏈」，而是**偷私鑰**：釣魚、惡意軟體、備份不當、助記詞外洩。

`web-03-auth-session` 的教訓在這裡被放大到極致：密碼可以改，**私鑰沒得改。**

## 鏈上沒有祕密

最後一個重要的資安心態：**「鏈上沒有祕密」。**

* 所有交易內容、金額、地址都是公開的。
* 你「以為藏起來」的資料，只要寫上鏈，就是永久公開。
* 分析師、執法單位、攻擊者都在讀同一本帳本。

所以任何「把敏感資料丟上鏈」的設計，都是設計層的漏洞——這正是 `web-04-ssrf-csrf-upload` 那句話的鏈上版本：「公開 ≠ 沒問題」。

#### Q: 為什麼區塊鏈上「私鑰外洩」的後果比「密碼外洩」嚴重得多？

* 因為私鑰比較長

* 因為鏈上只認私鑰，不認人；交易一旦上鏈無法撤銷，私鑰又無法重置

* 因為私鑰比較難記

* 因為鏈上會自動鎖定

> 💡 鏈上身分就是私鑰；持鑰即所有。私鑰外洩 = 資產被直接轉走且不可逆，也沒有『重置密碼』。
