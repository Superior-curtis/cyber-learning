# 白話資安名詞表

> 📅 2026-08-05 · 深入研究
> CVE、零時差漏洞、僵屍網路、SIEM、EDR、魚叉式釣魚——把那些嚇人的術語牆一次拆掉。所有常見名詞的短解釋，分成四個家族。

---

打開一篇資安文章，三句話之內就會撞上「CVE、CVSS 9.8、RAT，還有僵屍網路被用來竊取憑證」。不是你的問題——這個領域真的是術語工廠。

好消息是：這些詞可以分成四個家族，每個家族大概只有五個成員。這篇文章就是查詢表——每個詞一兩行白話解釋，按照家族分組，好記得多，還會告訴你書裡哪裡有深入版本。

## 家族一：誰在動手

攻擊背後的「人」和「機器」。

| 名詞 | 白話解釋 | 深入閱讀 |
|---|---|---|
| **威脅行為者（Threat actor）** | 「壞人」的正式叫法——個人、團體或國家 | `found-04-threat-modeling` |
| **RAT（遠端存取木馬）** | 會偷偷讓攻擊者遠端操控你電腦的惡意程式 | `cve-04-famous-1` |
| **僵屍網路（Botnet）** | 一大群被挾持的電腦（「殭屍」），由攻擊者統一控制——常被出租來做 DDoS 或發垃圾信 | `cve-04-famous-1` |
| **木馬（Trojan）** | 外表看起來有用或無害，其實背著隱藏壞任務的軟體 | `cve-04-famous-1` |
| **駭客（Hacker）** | 被媒體濫用的詞；本書大多用更精確的「攻擊者」 | `found-04-threat-modeling` |
| **APT（進階持續威脅）** | 有耐心、有資源的攻擊者（通常是國家級集團），打進來後可以潛伏數月 | `cve-04-famous-1` |

心智模型：**威脅行為者是「人」，僵屍網路是他的「軍隊」，RAT 和木馬是他把電腦招進軍隊的「工具」。**

## 家族二：攻擊怎麼進來

破門而入、造成傷害的手法。

| 名詞 | 白話解釋 | 深入閱讀 |
|---|---|---|
| **釣魚（Phishing）** | 大量發送假訊息（email、簡訊、聊天軟體），騙你點連結或交出祕密 | `blue-06-phishing-defense` |
| **魚叉式釣魚（Spear-phishing）** | 針對「某一個人」量身打造、用上對方真實資訊的釣魚——比亂槍打鳥危險得多 | `blue-06-phishing-defense` |
| **社交工程（Social engineering）** | 不攻擊程式，而是攻擊「人」——說服、假冒、製造急迫感 | `found-04-threat-modeling` |
| **勒索軟體（Ransomware）** | 把檔案加密、勒贖你付錢才解的惡意程式 | `blue-04-incident-response` |
| **DDoS（分散式阻斷服務）** | 用大量流量灌爆服務，讓真實用戶連不進去——攻擊可用性 | `found-02-cia` |
| **零時差漏洞（0-day）** | 廠商還不知道的漏洞，代表「零天」預警——目前沒有修補程式 | `cve-01-what-is-cve` |
| **漏洞利用（Exploit）** | 真的把漏洞變成傷害的程式碼或手法 | `cve-01-what-is-cve` |
| **PoC（概念驗證）** | 證明漏洞真的能被利用的小型（常是無害的）示範——證明 bug 是真的 | `cve-07-bug-bounty` |
| **後門（Backdoor）** | 繞過正常登入的隱藏通道——常由惡意程式植入，也可能出廠就存在 | `blue-01-hardening` |
| **鍵盤側錄（Keylogger）** | 默默記錄你敲的每個鍵、偷走密碼的軟體 | `cve-04-famous-1` |

心智模型：**漏洞是沒鎖的門，漏洞利用是開門的工具，零時差漏洞是「還沒人知道」的沒鎖的門，釣魚和社交工程則是去撬「人」這把鎖。**

## 家族三：業界怎麼歸檔漏洞

幫漏洞命名、描述、打分的系統。

| 名詞 | 白話解釋 | 深入閱讀 |
|---|---|---|
| **CVE** | 業界的漏洞資料庫，每個已知漏洞一個唯一編號——例如 CVE-2024-1234 | `cve-01-what-is-cve` |
| **CWE** | 漏洞「類型」的目錄——「SQL 注入」「密碼太弱」——也就是很多 CVE 共有的屬 | `cve-01-what-is-cve` |
| **CVSS** | 漏洞報告上那個 0.0 到 10.0 的嚴重度分數（9.8 代表「非常嚴重，快修」） | `cve-03-reading-a-cve` |
| **修補程式（Patch）** | 廠商對漏洞的修復——CVE 存在的意義，就是讓你知道該修什麼 | `cve-06-patch-management` |
| **揭露（Disclosure）** | 在公開之前先通知廠商處理 bug 的流程——「負責任的揭露」給廠商修復的時間 | `cve-02-lifecycle-disclosure` |

心智模型：**CWE 是「病名」，CVE 是「某個病人」，CVSS 是「病得多重」，修補程式是「藥」。**整台機器存在的目的，就是讓防禦者知道先修哪一個。

## 家族四：防禦者的工具箱

站在防守側的工具與做法。

| 名詞 | 白話解釋 | 深入閱讀 |
|---|---|---|
| **SIEM** | 把整個網路的日誌和告警集中到一個地方、幫分析師抓攻擊的系統 | `blue-02-logging-siem` |
| **SOC（資安監控中心）** | 全天候盯網路、處理告警的團隊與機房 | `blue-02-logging-siem` |
| **EDR** | 裝在每台電腦上、偵測可疑行為並能即時應對的資安軟體——現代版防毒 | `blue-01-hardening` |
| **MFA（多因子驗證）** | 登入要兩種以上不同「證明」——密碼加手機簡訊驗證碼 | `blue-07-iam-zero-trust` |
| **零信任（Zero trust）** | 一種哲學：誰都不預設可信，每個請求都驗證，內網也不例外 | `blue-07-iam-zero-trust` |
| **沙盒（Sandbox）** | 隔離環境，讓可疑檔案在裡面安全執行——就算真是惡意程式，也只會困在沙盒裡 | `blue-05-forensics` |
| **蜜罐（Honeypot）** | 故意放出來的假誘餌目標，引誘攻擊者上鉤，觀察他們的手法 | `blue-03-threat-intel` |
| **IoC（入侵指標）** | 攻擊留下的痕跡——某個 IP、檔名、雜湊值——用來偵測其他受害者 | `blue-03-threat-intel` |
| **事件處理（IR）** | 攻擊發生後的應變流程：隔離、根除、復原 | `blue-04-incident-response` |
| **VPN** | 為你的流量開一條加密隧道——在公共 Wi-Fi 上有用，但不是萬靈丹 | `net-04-firewalls-vpn-proxy` |

心智模型：**SIEM 是監控室，SOC 是裡面的值班團隊，EDR 是每層樓的保全，MFA 是每扇門上的加鎖，零信任是「誰來都要查證件」的管理哲學，沙盒是「開可疑郵件的密閉房間」，蜜罐是「假的金庫」。**

## 六十秒自我測驗

與其背定義，不如看場景認詞。下面的對話你八成在辦公室聽過：

| 你聽到的話 | 它大概是 |
|---|---|
| 「9.8 分的漏洞正在被大規模利用」 | CVSS 分數＋漏洞利用（可能還是零時差） |
| 「我們的帳號一直從同一批國家湧入」 | 僵屍網路／DDoS 或撞庫攻擊 |
| 「CEO 收到一封『IT』寄來的信，要密碼清單」 | 魚叉式釣魚／社交工程 |
| 「廠商出更新了，我們排個時間上線」 | 修補程式／修補管理 |

能指認出這些，你就已經比九成的新聞讀者強了。

## 長得很像的詞

資安一半的困惑不是來自新概念，而是來自長得很像的成對名詞。快速分法：

| 容易搞混的一對 | 分法 |
|---|---|
| CVE vs CWE vs CVSS | CVE 是「某一個 bug」、CWE 是「bug 的類型」、CVSS 是「這個 bug 有多嚴重」 |
| 釣魚 vs 魚叉式釣魚 | 一個灑網、一個瞄準——瞄準正是它危險的原因 |
| RAT vs 木馬 | 木馬是「送達方式」，RAT 是「被送達的東西」（遠端控制） |
| EDR vs 防毒 | 防毒比對已知特徵，EDR 觀察行為並能即時應對 |
| VPN vs Proxy | Proxy 轉送你的流量；VPN 另外把它加密 |
| SIEM vs EDR | SIEM 看整個網路的日誌；EDR 看每一台終端 |

當兩個詞感覺可以互換時，問「它們各自回答哪個問題」就行。上面的家族表，就是同一個技巧的放大版。

## 二十秒記完全部

如果只有二十秒，先抓住這四行：

```20&#x20;秒資安詞表

```

其他每個詞，都是這其中某一行的細節。

## 怎麼實際使用這份名詞表

三個習慣會讓術語比死背更快記住：

1. **先翻譯再記憶。**遇到新詞，強迫自己用一句白話說出來。「RAT = 能遠端控制的惡意程式。」說不出來，就代表還沒懂。
2. **問它屬於哪一族。**是「誰」（家族一）、「怎麼」（家族二）、「歸檔」（家族三）、還是「工具」（家族四）？家族告訴你它在事件裡扮演的角色。
3. **套進真實新聞。**隨便拿一篇資安新聞，指出：威脅行為者、手法（釣魚？）、有寫的 CVE、以及哪個防禦工具能攔下它。一篇新聞、四族各一名成員——整個領域就在這一個練習裡。

> 這份名詞表是地圖，不是領土。這裡每個詞背後都有一整篇文章。當某個詞一直出現，那就是訊號：該去讀它的主文章了——上面的表格告訴你去哪裡。
