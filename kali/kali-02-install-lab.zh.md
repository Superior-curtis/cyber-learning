# 安裝與建置自己的練習環境（VM / CTF）

> 📅 2026-08-05 · 使用教學
> 練功的地方，要比練功本身更重要。這篇教你用虛擬機建立一個完全隔離、安全又免費的練習環境——Kali 加上幾台刻意脆弱的靶機，就是屬於你自己的小型 HackTheBox。

---

在 `kali-01-what-is-kali` 你認識了工具，也知道了界線。現在的問題是：**要去哪裡練，才不會誤踩那條界線？**

答案很簡單也很重要：**在自己的虛擬機裡練。** 虛擬機（VM）是一台「裝在你電腦裡的電腦」——你在裡面做的任何事，都影響不到你的真實系統與真實網路。這篇教你把它建起來，而且完全免費。

## 為什麼要 VM / 隔離

練習安全工具，最忌諱的就是「在真實系統上亂試」。三個理由讓你一定用 VM：

1. **安全**：掃描、測試、惡意檔案——全都被關在虛擬機裡，傷害不到你的真實系統。
2. **可拋棄**：玩壞了，直接刪掉重來，五分鐘恢復。
3. **合法**：你對自己的 VM 有 100% 的授權，永遠不會誤踩界線。

> 鐵律：練習環境必須與真實網路隔離。 如果虛擬機直接連進你家的真實區域網路，它就可能掃描到你家裡其他真實裝置——那就不再是「練習」了。下面的網路設定就是要避免這件事。

## 安裝 Kali：概觀

完整的安裝步驟會因版本而異，這裡給你**最重要的概念骨架**：

| 步驟 | 重點 |
|---|---|
| 1. 裝虛擬機軟體 | 免費的 VirtualBox 或 VMware Workstation Player 都可以 |
| 2. 下載 Kali 映像 | 從官方網站下載 VM 映像檔（預先設定好的版本，省事很多） |
| 3. 匯入 | 在虛擬機軟體裡「匯入」映像檔，開機即可 |
| 4. 更新 | `sudo apt update && sudo apt upgrade`，把工具更新到最新 |
| 5. 快照 | 設定好之後建立一個快照（snapshot），之後隨時可以還原 |

對新手來說，**用官方預先建好的 VM 映像** 比從 ISO 安裝簡單太多——省掉一堆驅動與設定。

## 練習目標：刻意脆弱的靶機

光有 Kali 不夠，你還要「靶子」來打。這些**刻意做得不安全**的練習目標，是安全社群專門設計給人練習的：

| 靶機 | 練習什麼 |
|---|---|
| Metasploitable | 大量已知漏洞的 Linux，適合初學者 |
| DVWA | 刻意脆弱的網頁應用，練注入與 XSS |
| OWASP Juice Shop | 更完整的脆弱網頁應用，練 OWASP Top 10 |

這些靶機的安裝與使用，`lab-02-vulnerable-targets` 會詳細展開。這裡只要記住：**它們都存在 VM 裡，與你的真實系統完全隔離。**

## 網路設定：關鍵的一步

練習環境最容易被忽略的就是網路。虛擬機軟體通常提供幾種模式：

* **NAT**：虛擬機透過你的主機上網，但外面看不見它——**練習環境推薦用這個**。
* **Host-Only**：只有你的主機與虛擬機能互相訪問，完全不連外網。
* **橋接（Bridged）**：虛擬機像一台真實裝置直接連進你的區域網路——**練習時避免用這個**，除非你很清楚自己在做什麼。

> 推薦組合：Kali 用 NAT，靶機用 Host-Only，兩者共用一個隔離網段。 這樣 Kali 掃得到靶機、卻碰不到你家的真實網路——練得放心又合法。

#### Q: 為什麼練習安全工具一定要用隔離的虛擬機？

* 因為虛擬機跑得比較快

* 因為能把測試關在安全區內、不會影響真實系統與真實網路，而且對自己的 VM 擁有完整授權

* 因為 Kali 不能在真實系統上安裝

* 因為虛擬機比較便宜

> 💡 VM 提供隔離（不會波及真實系統）、可拋棄（玩壞重來）與授權明確（自己的 VM）三個好處。
