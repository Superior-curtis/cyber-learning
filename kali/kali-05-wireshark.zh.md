# Wireshark：封包分析

> 📅 2026-08-05 · 使用教學
> Burp 讓你看懂網頁請求，Wireshark 讓你看到網路上真正流過的每一段資料。這篇帶你認識封包分析——介面、基本過濾，以及怎麼用它找出可疑的連線。

---

`kali-04-burp-suite` 讓你看懂「應用層」的請求。但真正的網路世界還有一層更底層的風景：**封包（packet）**——網路上真正流過的一小段一小段資料。

**Wireshark** 就是看這層風景的工具。它是資安界公認的封包分析標準：抓下流量、逐一檢視封包、用過濾器在數千個封包裡找出你要的那幾個。

## 封包是什麼

電腦在網路上傳輸資料時，不是一次送一大包，而是切成一段段的 **封包**。每個封包就像一封信，包含：

* **來源與目的**：誰寄的、寄給誰（IP 與埠）。
* **協定資訊**：這封信的「格式」——TCP、UDP、HTTP 等。
* **內容**：實際的資料。

Wireshark 做的事，就是把這些信一封封拆開給你看：來源、目的地、用了什麼協定、內容是什麼。

## 介面概觀

Wireshark 的介面初看很嚇人，其實只需要懂三塊：

| 區塊 | 顯示什麼 |
|---|---|
| 封包清單 | 每個封包一行，時間、來源、目的、協定、摘要 |
| 封包細節 | 點開某個封包，分層展開各欄位 |
| 十六進位檢視 | 封包的原始位元組 |

新手第一步：**抓一小段流量，點幾個封包，看協定層層展開。** 你會親眼看到「一封 HTTP 請求」在細節裡長什麼樣。

## 基本過濾：從大海撈針

抓下來的流量動輒幾千個封包。**顯示過濾器（display filter）** 是從裡面撈出目標的關鍵：

```
# 只看特定 IP 的流量
ip.addr == 192.168.1.10

# 只看 HTTP 請求
http

# 只看 DNS 查詢
dns

# 組合條件
http and ip.addr == 192.168.1.10
```

> 記住這個順序：先抓，再過濾，再檢視。 新手常見的錯誤是一次想抓「剛剛好」的流量——與其精準抓取，不如先全抓下來，再用過濾器撈。過濾器就是你的搜尋框。

## 資安用途

Wireshark 在資安上的用途，藍隊與學習者都常用：

* **看懂協定**：把 `net-01` 到 `net-04` 學的 TCP、TLS、DNS 變成看得見的封包。
* **找可疑連線**：大量對外連線、奇怪的埠、沒有預期的流量，都會在封包清單現形。
* **驗證加密**：確認流量真的走 HTTPS（內容是加密的），還是裸奔。
* **鑑識分析**：`blue-05-forensics` 會講到，分析可疑的網路活動常常從封包開始。

練習時，**只抓自己 VM 環境的流量**——`kali-02-install-lab` 的隔離網段就是為此設計的。不要對別人的網路抓包。

#### Q: 要從幾千個封包裡找出「某個 IP 的 HTTP 流量」，最有效的方法是？

* 一個一個封包慢慢看

* 使用顯示過濾器，例如 http and ip.addr == 192.168.1.10

* 重新抓一次流量

* 關掉 Wireshark 用文字編輯器開啟抓包檔

> 💡 顯示過濾器是 Wireshark 的搜尋框；先抓全量、再用條件過濾，是從大海撈針的正確方式。
