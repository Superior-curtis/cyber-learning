# 密碼工具實戰（hydra、hashcat）

> 📅 2026-08-05 · 使用教學
> hydra 與 hashcat 常被混為一談，其實它們解決兩件完全不同的事：一個在「線上」測試登入，一個在「離線」測試雜湊。這篇把分工講清楚，並接到你在密碼章學過的機制。

---

在 `pass-02` 與 `pass-03`，你知道了密碼破解的機制與 hashcat/John。現在把視角切到工具本身：Kali 裡有兩把常被混為一談的密碼工具——**hydra** 與 **hashcat**。它們其實在做**完全不同**的兩件事。

> 授權提醒：以下工具只用於你自己的系統，或有授權的測試。對未授權的目標跑登入測試或雜湊破解，就是攻擊，在多數地方違法。練習請在 kali-02-install-lab 的虛擬機環境進行。

## 兩種密碼攻擊的區別

密碼測試分成兩大類，工具的選擇取決於你「面對什麼」：

| | 線上（online） | 離線（offline） |
|---|---|---|
| 面對的是 | 一個登入介面 | 一份雜湊檔案 |
| 你在做 | 反覆送出登入嘗試 | 本地算出雜湊來比對 |
| 代表工具 | hydra | hashcat |
| 限制 | 伺服器會鎖定/限速 | 只需要算力與時間 |

一句話記住：**hydra 敲門，hashcat 拆鎖。** 一個在真實的登入介面上測試，一個在已經拿到的雜湊上計算。

## hydra：線上登入測試

hydra 對**真實的登入介面**送出大量登入嘗試，測試「這組帳號/密碼在不在」：

```
# 測試某個網站的表單登入（示意）
hydra -l admin -P /usr/share/wordlists/rockyou.txt 127.0.0.1 http-post-form \
  "/login:user=^USER^&pass=^PASS^:Invalid login"
```

對防守方而言，hydra 存在的意義是**提醒你限流有多重要**：如果沒有嘗試次數限制與鎖定，這種工具可以一秒試出成千上萬個密碼——這正是 `pass-04-defenses` 講「鎖定策略」的原因。

## hashcat：離線雜湊破解

hashcat 面對的是**你已經擁有的雜湊值**（例如自己的資料庫備份），在本地用 GPU 高速計算來比對。`pass-03-cracking-tools` 已經詳細講過它，這裡只複習一句話：

```
# 對一份雜湊檔案做字典攻擊（示意）
hashcat -m 0 hashes.txt /usr/share/wordlists/rockyou.txt
```

它的「敵人」不是伺服器，而是**演算法本身**——這正是 `crypto-02-password-hashing` 說「慢的雜湊才有價值」的由來。

> hydra 與 hashcat 的共同點只有名字裡有「密碼」。 線上攻擊受伺服器限制，離線攻擊受演算法與算力限制；了解你要面對哪一種，才知道該用哪一把。

## 防守方怎麼看

把工具換成防守方的鏡頭，這些名字全部變成「檢查自己的清單」：

* 自己的系統有沒有**限流與鎖定**，擋得住 hydra 這類線上測試？
* 自己存的密碼是不是**慢雜湊 + 鹽**（argon2/bcrypt），讓 hashcat 無功而返？
* 自己的弱密碼清單，是不是該用同樣工具先掃一遍？

`pass-04-defenses` 把這幾條擴展成完整的防禦策略。工具能做的，是讓你把「假設」變成「實測」。

#### Q: hydra 與 hashcat 的最大區別是什麼？

* 一個是 Linux 工具，一個是 Windows 工具

* hydra 在線上面對登入介面測試，hashcat 在離線面對雜湊計算

* hydra 只能破解 Wi-Fi

* hashcat 不能用在 Kali 上

> 💡 hydra 敲門（線上登入測試），hashcat 拆鎖（離線雜湊破解）；要面對哪一種問題，決定用哪一把。
