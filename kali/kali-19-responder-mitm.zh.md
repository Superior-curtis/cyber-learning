# Responder 與中間人攻擊：邏輯與防禦

> 📅 2026-08-05 · 深入研究
> 中間人攻擊讓攻擊者站在「資料流的中間」偷看或竄改。Responder 是最典型的 LAN 工具——它利用名稱解析的順序，讓裝置把憑證雜湊送到攻擊者手上。這篇講透邏輯、homelab 指令與藍隊防禦。

---

`net-01-network-fundamentals` 講了網路怎麼把資料送達。中間人（MITM）攻擊利用的正是這個「送達」過程——**讓資料先經過攻擊者的手。**

`Responder` 是這個領域最經典的工具。這篇講透它的邏輯、給出 homelab 指令，並把藍隊防禦放到同等份量。

> 安全說明（HOMELAB ONLY）：Responder 的所有用法只限你自己的 homelab 網段。在真實或他人的區域網路上執行，就是在攔截他人憑證——這是嚴重的犯罪。

## 中間人攻擊在做什麼

中間人攻擊的邏輯很直白：**正常情況，A 直接送資料給 B；中間人讓資料先經過自己，再轉送。** 於是它能：

* **偷看**：讀取經過的明文資料。
* **竄改**：在轉送時改內容。
* **蒐集**：在經過時記下帳號、密碼、雜湊。

要當中間人，你得先「騙過」雙方的路由——而網路世界提供了好幾種「騙法」。

## Responder 的邏輯：毒化名稱解析

Responder 利用的是一個很具體的機制：**Windows 的名稱解析順序**。當使用者打一個「非網域」的名字（例如 `\\fileserver`），系統會依序問：

1. DNS → 找不到。
2. **LLMNR / NBT-NS** → 用廣播問「誰是 fileserver？」

Responder 做的就是**回應這些廣播**：「我就是 fileserver！」於是使用者把憑證雜湊送過來——**送給了攻擊者**，而攻擊者轉手就能離線破解（`pass-03-cracking-tools`）。

> 記住這個邏輯：攻擊者「假裝是你要找的那台機器」，讓你把密碼自己送上門。 這跟 kali-16-camphish 的「假登入頁」是同一個心理，只是手法從網頁換成網路協定。

## homelab 指令（只限自己的網段）

在你自己隔離的 homelab 網段，安裝與啟動：

```bash
# 安裝
sudo apt install responder

# 在你自己的 LAN 介面啟動（HOMELAB ONLY）
sudo responder -I eth0
```

執行後，Responder 會「聽」網段上的名稱解析廣播並回應。在 homelab 的意義：**驗證「如果網段上有一台惡意機器，我的裝置會不會送憑證出去」**——這是防禦演練，不是攻擊。

> 安全說明（再次強調）：在真實或他人網路上跑 Responder，等於攔截別人的憑證——嚴重犯罪。homelab 實驗做完，立刻關掉並觀察：「你的裝置竟然回應了」本身就是該修的問題。

## 藍隊防禦

Responder 的防禦，幾乎全在「設定」層：

| 措施 | 做法 |
|---|---|
| 關閉 LLMNR / NBT-NS | 讓名稱解析只剩 DNS——Responder 無戲可唱 |
| 啟用 SMB 簽章 | 讓竄改與偽裝被偵測 |
| 網路分割 | 把敏感網段隔離，減少廣播可達範圍（`net-01` 網段） |
| 最小權限 | 就算雜湊被拿走，能開的門也少 |
| 監控 | 異常的名稱解析廣播量，`blue-02-logging-siem` 的基線思維 |

> 最高防禦心態：Responder 靠「你開了多餘的協定」成功。 關掉 LLMNR/NBT-NS，這個工具的效果直接歸零——設定比工具本身更能決定成敗。

## 安全說明

* ✅ 可以：在你**自己的 homelab 網段**，對**你自己的裝置**做上述演練。
* ❌ 不可以：在真實或他人的網路上攔截憑證。
* ⚠️ 記住：中間人攔截是犯罪，且完全可以用防禦設定擋掉——你該學的是「怎麼關」而不是「怎麼開」。

MITM 與 Responder 的邏輯清楚了。想從「人」的角度看另一種攔截——釣魚與社交工程——`blue-06-phishing-defense` 是完整章節；想看網段與隔離，`net-01-network-fundamentals` 的網段概念是基礎。

#### Q: Responder 成功的主要原因是什麼？

* 它破解了加密演算法

* 它回應了名稱解析的廣播，讓裝置以為『它就是要找的那台機器』，因而把憑證雜湊送給它

* 它直接竄改了 DNS 伺服器

* 它利用了伺服器的漏洞

> 💡 Responder 靠『假裝是你要找的機器』來騙取名稱解析，裝置因此把憑證雜湊送上門；所以防禦重點是關閉 LLMNR/NBT-NS。
