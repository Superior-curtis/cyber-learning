# Wi-Fi 稽核：驗證你自己 AP 的加密

> 📅 2026-08-05 · 使用教學
> 你的 Wi-Fi 密碼到底夠不夠強？Wi-Fi 稽核用監聽模式 + 握手 + 離線測試，驗證『你自己 AP』的加密強度。這篇講透邏輯、homelab 指令，以及為什麼只限你自己的 AP。

---

`net-03-wifi-security` 教你怎麼設 Wi-Fi 加密。現在動手驗證：**你的 Wi-Fi 密碼到底扛不扛得住離線測試？** 這就是 **Wi-Fi 稽核**。

> 安全說明（HOMELAB ONLY）：以下所有步驟只允許針對你自己的無線網路/路由器。攔截或測試他人的 Wi-Fi 訊號，在多數地方是嚴重犯罪——即使只是「看看」。

## Wi-Fi 稽核在做什麼

Wi-Fi 稽核的目標一句話：**用攻擊者的視角，驗證你自己的無線加密強度。** 它把 `net-03-wifi-security` 講的 4-way handshake，實際「走一遍」——但對象是你自己的 AP。

## 邏輯：握手與離線測試

還記得 `net-03-wifi-security` 的 4-way handshake 嗎？稽核的邏輯建立在那之上：

1. **監聽模式**：把無線網卡切成監聽模式，收得到空中所有封包。
2. **抓握手**：當**你自己的裝置**連上**你自己的 AP** 時，抓住那次握手。
3. **離線測試**：用字典對握手做離線破解——`pass-03-cracking-tools` 的機制。

**關鍵：握手本身不暴露密碼，但可以用「字典猜」來測——而猜的速度由你的密碼強度決定。**

## homelab 指令（只限自己的 AP）

整套流程（`kali-13-wireless-tools` 的三把工具）：

```bash
# 1. 看你的無線網卡，切成監聽模式（HOMELAB ONLY）
sudo airmon-ng start wlan0

# 2. 掃描並鎖定你自己的 AP（記下 BSSID 與頻道）
sudo airodump-ng wlan0mon

# 3. 抓你自己的裝置與你自己的 AP 之間的握手
sudo airodump-ng -c <頻道> --bssid <你自己的AP的BSSID> -w capture wlan0mon

# 4. 對抓到的握手做離線測試（驗證你自己的密碼強度）
sudo aircrack-ng -w /usr/share/wordlists/rockyou.txt capture-01.cap
```

> 安全說明（再次強調）：這些步驟的對象只允許是你自己的 AP 與你自己的裝置。對任何別人的 Wi-Fi 執行，就是非法攔截無線通訊——刑事犯罪。

## 結果怎麼解讀

離線測試的結果，直接告訴你一件事：**你的密碼在字典面前能撐多久。**

* 幾秒就被試出 → 密碼太弱，換成 `pass-04-defenses` 的「長而隨機」。
* 試不出來 → 你的密碼強度夠，`net-03` 的建議奏效。

> 這正是 crypto-02-password-hashing 那句話的 Wi-Fi 版：強度靠「長而隨機」，不靠「記得住」。 Wi-Fi 密碼也不例外。

## 藍隊防禦

| 措施 | 做法 |
|---|---|
| 加密世代 | WPA3（或 WPA2-AES），拒絕 WEP/TKIP（`net-03`） |
| 密碼強度 | 長而隨機的 passphrase，不用單字或日期 |
| 關閉 WPS | WPS PIN 可被暴力試出（`net-03` 的警告） |
| 隱藏功能 | 關閉管理介面的公網暴露 |

> 最高防禦心態：Wi-Fi 稽核不是『攻擊教學』，是『自驗收』。 用同樣的工具先掃自己，才知道該換密碼、該升級世代——這正是 blue-01-hardening 的『先知道自己暴露了什麼』在無線上的版本。

#### Q: Wi-Fi 稽核『抓握手再離線測試』，測的其實是什麼？

* AP 的硬體速度

* 你的 Wi-Fi 密碼強度——字典離線測試能多快猜出它

* 路由器的品牌

* 訊號強度

> 💡 離線測試用字典去猜握手裡的密碼；猜得越快代表密碼越弱。這讓『密碼夠不夠強』變成可實測的問題。
