# Forensics 題型入門

> 📅 2026-08-05 · 使用教學
> Forensics 是 CTF 最「動手」的題型：給你一個檔案或磁碟映像，裡面藏著旗標。這篇教你一套起手式——file、strings、exiftool、binwalk——從「拿到檔案」走向「挖出旗標」。

---

`kali-11-forensics-tools` 讓你認識了四把鑑識工具。現在把它們用起來：**Forensics 題型**——CTF 裡最「動手」的題型。

規則很簡單：主辦單位給你一個檔案（圖片、文件、磁碟映像……），旗標藏在裡面。你要靠工具把它挖出來。這篇給你一套能直接上手的起手式。

## Forensics 題在做什麼

Forensics 題的本質是**「從檔案裡找線索」**。旗標可能藏在：

* 檔案結尾塞的一段文字。
* 圖片或文件的元資料裡。
* 一個「藏著另一個檔案」的檔案裡。
* 刪除或隱藏的檔案。

對應的工具就是 `kali-11-forensics-tools` 那四把——而解題的起手式，幾乎每次都是同一個順序。

## 起手式：拿到檔案先做四件事

```bash
# 1. 先看這是什麼檔案（別被副檔名騙了）
file mystery.bin

# 2. 撈出所有可讀字串
strings mystery.bin | less

# 3. 看元資料
exiftool mystery.bin

# 4. 看有沒有藏著其他檔案
binwalk mystery.bin
```

> Forensics 的鐵律：先讓工具說話，再動手猜。 這四道指令跑完，大多數題目的「方向」就浮出來了——剩下的往往是照著線索往深挖。

## 常見考點

| 考點 | 長相 | 解法 |
|---|---|---|
| 藏字串 | 旗標直接塞在檔案裡 | `strings` |
| 藏檔案 | 一個檔案裡嵌著另一個 | `binwalk` 拆出、再處理 |
| 元資料 | 線索藏在作者/註解/GPS | `exiftool` |
| 磁碟映像 | 整個磁碟等你分析 | Autopsy 或掛載映像 |
| Stego | 訊息藏進圖片像素/音訊 | 視具體工具（stegsolve 等） |

「Stego（隱寫）」常被歸在 Forensics 底下——訊息藏在圖片或聲音的細節裡，肉眼看不出來，要特定工具才能還原。

## 練習心法

* **照流程走**：`file` → `strings` → `exiftool` → `binwalk`，每次都用同一套起手式，速度快很多。
* **別被副檔名騙**：`.png` 可能是偽裝的，`file` 才是真相。
* **記住旗標格式**：`lab-03-ctf-101` 說過，找「符合格式的一段文字」常常就是答案。

> 誠實提醒：解題卡住時，先確認「我是不是漏了最簡單的一步」。很多 Forensics 題的旗標，就明晃晃地躺在 strings 的輸出裡——只是你忙著找複雜解法，沒看它。

#### Q: 拿到一個 Forensics 題的檔案，標準起手式是什麼？

* 直接打開當文字檔看

* 用 file 確認類型，再用 strings / exiftool / binwalk 依序檢查

* 重新下載題目

* 先猜一個答案

> 💡 file 確認真相、strings 撈字串、exiftool 看元資料、binwalk 拆內嵌——這四步是 Forensics 的標準起手式。
