# 為什麼資安世界被 Linux 統治

> 📅 2026-08-05 · 核心概念
> 伺服器、雲端、容器幾乎全都跑在 Linux 上，資安工具也永遠先出 Linux 版。這不是巧合——它是整個資安世界的前提心智模型。

---

所有資安故事的背景，都是同一台機器。電影裡的駭客敲幾下鍵盤就能入侵一切；而在現實世界裡，那些鍵盤敲下去所面對的系統，幾乎全是 Linux。這聽起來像誇飾，但它是整個資安領域最關鍵的一件事：**伺服器、雲端、容器，幾乎全跑在 Linux 上；資安工具，幾乎都先出 Linux 版。**如果你想把這個領域讀懂，Linux 不是你「可以選修」的科目——它是地板。

這篇文章不教你打指令，而是先建立**心智模型**：為什麼偏偏是 Linux？以及為什麼學它，會解鎖後面所有章節。

> 限授權使用——本書是防禦導向、教育性質的參考書：所有的系統操作與測試，都以你自己的機器、CTF 練習環境、或你獲得授權的環境為對象。未經授權去探測或攻擊別人的系統，在多數國家是違法的，甚至可能構成刑事犯罪。學 Linux，是為了讀懂與保護系統，不是為了打別人的機器。

## 先認識三種「電腦」

在談 Linux 之前，先說清楚一件事：你平常用的電腦，和你透過網路連到的電腦，是兩種不同的生物。

* 你的**桌面電腦**（Windows 或 macOS）：你親手操作，有螢幕有滑鼠，設計目標是「好用」。
* 那台**伺服器**：沒有螢幕，放在機房或雲端，唯一的工作是回應網路上的請求，設計目標是「可靠」。
* 還有第三種，更看不見的——**容器**（container）：把一支程式連同它的環境打包成一個輕量「盒子」，幾秒鐘就能開出幾百個。

你每天打開的任何網站、任何 App 的後端、收信、看影片，背後都有一台（或很多台）伺服器在忙。而這些伺服器、以及裝著程式的容器，絕大多數跑的是 Linux。

## 90% 的網際網路，站在 Linux 上

「絕大多數」到底是多數？具體比例會逐年浮動，但方向幾十年不變：

| 網路上的角色 | 主流的作業系統 |
|---|---|
| 全球大型網站（Google、Amazon、Meta） | 幾乎清一色 Linux |
| 雲端虛擬機器（AWS、GCP、Azure） | 以 Linux 為最大宗 |
| 手機的骨幹（Android） | Android 的核心就是 Linux 核心 |
| 路由器、NAS、智慧裝置 | 大多是嵌入式 Linux |
| 桌面電腦 | Windows 與 macOS 佔大頭——這是唯一的例外 |

唯一 Linux「輸」的地方，是你腳邊那台桌面電腦。但資安事件的主角不是桌面——是**伺服器**。攻擊者要的是資料、運算力、對服務的控制權，而這些東西全部住在伺服器上。跟著伺服器走，你就會走到 Linux。

## 工具為什麼都先出 Linux 版

把視線轉到工具。Kali Linux、Metasploit、Wireshark、nmap、hashcat——幾乎所有你聽過的資安工具，**第一個版本都是 Linux 版，而且多數只做 Linux 版**。為什麼？

| 原因 | 說明 |
|---|---|
| 目標就在那兒 | 攻防的對象都是伺服器，而伺服器是 Linux |
| 開源文化 | 資安工具很多是開源的，天然長在開源系統上 |
| 指令與腳本 | 大量工作就是打指令、寫腳本，Linux 天生適合 |
| 輕量又可重製 | 在虛擬機或容器裡，幾分鐘就能開出一台乾淨的測試環境 |

這不是巧合，而是生態系彼此餵養：**跑在 Linux 上的系統，由住在 Linux 的工具保護（與測試），這些工具又吸引更多人跳進 Linux。**你在 `kali-01-what-is-kali` 會看到這條生態系長成什麼樣。

## 一個名字，一整個家族

「Linux」不是一個作業系統，而是一整個家族。核心（kernel）是同一個，但圍繞它的**發行版（distribution）**各有一套工具、安裝方式與更新節奏。常見的幾家：

| 發行版 | 特色 | 資安世界的地位 |
|---|---|---|
| Ubuntu / Debian | 入門友善、套件龐大 | 學習與伺服器的主力 |
| RHEL / Rocky / Alma | 企業伺服器、支援週期長 | 公司機房的常客 |
| Arch | 極簡、DIY、文件極好 | 高手自己動手時的樂園 |
| Alpine | 超小 | 容器映像的最愛 |
| Kali / Parrot | 預裝資安工具 | CTF 與授權測試的百寶箱 |

入門時不必捲入「哪一家最好」的戰爭。**底層的目錄結構、權限、指令，所有發行版幾乎一模一樣**——接下來教你的東西，在每一家都通用。等到 `kali-01-what-is-kali`，你會看到一個把整套工具預裝好的特殊成員。

## Unix 的遺產：為多使用者而生的機器

Linux 不是憑空冒出來的。它是 **Unix**（1970 年代的作業系統）的精神繼承者，而 Unix 有一個對資安非常關鍵的設計起點：**它從第一天起就是「多使用者」系統**——一台機器同時服務許多人，每個人的檔案必須互不干擾。

這個對比很鮮明：個人電腦時代的系統，設計預設是「一個使用者、一台機器」；而 Unix/Linux 預設就是「一台機器、很多人」。因此它天生具備：

* 內建的**身分、群組、權限**——「誰能做什麼」是核心概念，不是事後補丁（`linux-03-permissions` 的主角）。
* 強烈的**日誌文化**——多人共用一台機器，必須記錄誰做了什麼（`linux-07-logs-auditing` 的主角）。
* 開源的**原始碼文化**——全世界都在看同一份程式碼，漏洞被發現得快、修補得也快。

這就是資安世界最後選中它的原因：**一個從核心就把「多使用者與可見性」刻進設計的系統，天生適合當攻防的舞台。**

## 日誌：資安的「燈光」

想像你在深夜走進一間漆黑的機房。你怎麼知道發生過什麼事？答案是燈光——而在資安世界，燈光叫做**日誌（log）**。

Linux 把所有重要事件寫進 `/var/log`：誰登入、誰登入失敗、系統有沒有異常、服務有沒有重開。幾個你很快會認得的常見檔名：

| 日誌檔 | 記錄什麼 |
|---|---|
| `/var/log/auth.log` | 登入與認證事件 |
| `/var/log/syslog` | 系統與程式的雜項訊息 |
| `/var/log/dmesg` | 開機與核心訊息 |
| `/var/log/nginx/access.log` | 網頁伺服器的存取紀錄 |

防禦者的事故調查、藍隊的監控、甚至 CTF 的解謎，一大半都在讀這些檔案。

這對你有一個實際的好處：**Windows 的日誌散在一個複雜的事件檢視器裡；Linux 的日誌就是「檔案」，而且住在一個可預測的目錄結構裡。**學習 Linux，等於同時學習「這台機器自己的筆記寫在哪、怎麼讀」。那是 `linux-07-logs-auditing` 的主角——但你要先知道 `/var/log` 這個詞，才聽得懂它。

## 為什麼這是一切的「地板」

把前面三件事疊起來，你得到整個資安世界的地形圖：

| 你想學的方向 | 它其實建立在哪 | 先需要的 Linux 知識 |
|---|---|---|
| 網路掃描 | 掃描的對象是 Linux 伺服器 | 進程、連線、指令 |
| 網頁漏洞 | 網站跑在 Linux 上、日誌在 `/var/log` | 目錄結構、權限 |
| 密碼學與破解 | 工具幾乎都是 Linux 指令 | 檔案、權限、Shell |
| 藍隊防禦 | 監控與 SIEM 讀的都是 Linux 日誌 | 日誌、進程、服務 |
| CTF 與滲透測試 | Kali 就是一套 Linux 發行版 | 全部 |

不管你想往哪個方向走，路都先經過 Linux。這不是因為 Linux 比別的好——它是**大多數電腦實際在跑的那個東西**。學資安不碰 Linux，就像想當航海員卻說「我不想碰海水」。

## 用 Linux 想事情的三個習慣

建立 Linux 心智模型，其實是建立三個習慣：

* **看到路徑，就拆出地圖。** `/etc/ssh/sshd_config` 不是一串字元，而是「設定檔 → SSH → 它的設定」的地址。拆得開路徑，你就能在陌生機器上自己找路。
* **看到權限，就問誰能寫。** 一個檔案的價值不在內容，而在「誰可以改它」。能改設定、改程式的人，就是能操控這台機器的人。
* **看到事件，先找日誌。** 任何「剛剛發生什麼」的疑問，第一反應都是 `/var/log`。系統自己記了筆記，別急著瞎猜。

這三個習慣貫穿整條 Linux 系列——往後每一章，都是在其中某個習慣上加細節。

> 把 Linux 想成「會話的語言」，而不是「一門課」。 接下來很多文章會頻繁出現 ls、cd、cat、chmod 這些指令。你不需要一次背完——但每一次看到，停一下，看懂它在做什麼。整條 Linux 系列（linux-02-filesystem 一直到 linux-09-hardening-basics），就是在幫你建立這門語言的地基。

## 資安的日常都在黑底白字裡

最後補一個你可能已經注意到的現象：資安文章裡出現的畫面，很少是漂亮的視窗，而是一片**黑底白字的終端機**（terminal）。這是因為伺服器根本沒有螢幕，所有人都用「文字」遠端連進去操作——而這個「用文字操作系統」的介面，叫做 **Shell**。

Shell 是資安工作者的主戰場：掃描、看日誌、改權限、查進程，全是一行一行的指令。好消息是，你不需要天生喜歡它才能學——**它只是另一種「說話方式」**，而且規則非常固定。`linux-06-shell-essentials` 會把這門語言的核心講完。

現在別急著學指令。這一章的任務只有一個：**確信 Linux 值得學。**如果你已經開始相信「伺服器、工具、日誌都在這裡」，那你的地板已經鋪好了。

## 下一步

先建立「為什麼」，下一篇文章我們走進機器內部：**Linux 檔案系統與目錄結構**——`/`、`/etc`、`/var`、`/home`、`/tmp` 各是幹嘛的，以及為什麼「一個檔案住在哪個目錄」本身就是一種資安資訊。就是 `linux-02-filesystem`。

#### Q: 為什麼說「學資安先學 Linux」是整個領域的前提心智模型？

* 因為 Linux 是市場上最容易入手的作業系統

* 因為伺服器、雲端與容器大多跑 Linux，而資安工具也優先為它開發

* 因為 Windows 系統不存在資安問題

* 因為所有駭客電影都用 Linux 當道具

> 💡 網際網路的骨幹（伺服器）、雲端虛擬機器與容器，大多跑 Linux；資安工具也優先支援它。要防禦並理解這個世界，Linux 是必須的地板，而不是選修科目。
