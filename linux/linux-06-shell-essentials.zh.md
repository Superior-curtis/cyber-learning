# Shell 指令速成（給資安人）

> 📅 2026-08-05 · 使用教學
> 在真實的資安工作裡，你一半的時間活在文字介面。這篇幫你把最常用的工具磨利：管線、grep、find，與一行指令解決問題的手感。

---

真人版的資安工作，不像電影裡全是圖形介面。調查一台主機、翻一份日誌、比對幾千行文字——這些事最順手的工具是 **shell**。它是你在黑暗伺服器房裡的手電筒：學會它，你才真正開始「看得見」。

這篇文章不是要你背指令，而是給你一組**有手感**的工具。每一節一個工具、一個真實場景，最後串成幾個可以直接用的一行指令。

## 管線與重導向：把指令接起來

Shell 的靈魂是「把很多小工具串起來」。核心符號有四個：

| 符號 | 意思 | 例子 |
|---|---|---|
| `\|` | 把左邊的輸出，餵給右邊的輸入 | `ps aux \| grep ssh` |
| `>` | 把輸出寫進檔案（覆蓋） | `ls > list.txt` |
| `>>` | 把輸出加在檔案尾端 | `echo done >> log.txt` |
| `2>` | 把錯誤訊息導向別處 | `cmd 2> err.txt` |

想通了這四個符號，你就擁有了組合技：`ps aux | grep ssh` 的意思是「列出所有程序，只留下包含 ssh 的那幾行」。這是資安界使用頻率第一名的一行指令。

## grep：在文字裡找東西

`grep` 從輸入中過濾出「含有某個字樣」的行。它是你的搜尋器，也是你的初步過濾器：

```bash
grep -i error /var/log/syslog      # 不分大小寫找 error
grep -r "Password" /etc/           # 遞迴搜尋整個目錄
grep -v "^#" /etc/ssh/sshd_config  # 反向過濾：去掉以 # 開頭的註解行
```

`-i` 不分大小寫、`-r` 遞迴進資料夾、`-v` 反過來選「不含」的行、`-E` 開啟擴充正規表達式。看日誌時，`grep` 是你最好的朋友：

```bash
grep -iE "error|fail|denied" /var/log/auth.log | tail -50
```

這一行會把認證日誌裡所有錯誤、失敗、被拒絕的紀錄撈出來，只看最後 50 行。對，就是這麼樸素，但異常幾乎都是這樣被找到的。

## find：在檔案系統裡找東西

`grep` 找文字，`find` 找**檔案**。它會遞迴走過指定目錄，照條件篩選：

```bash
find /var/log -name "*.log" -mtime -7   # 7 天內改過的 .log 檔
find / -type f -size +1G                # 所有超過 1GB 的檔案
find / -perm -4000 2>/dev/null          # 有 setuid 的程式
```

最後一個值得記住：setuid 程式會用擁有者的權限執行，是攻擊者愛找的目標。`2>/dev/null` 把「權限不足」的錯誤訊息丟掉，讓輸出乾淨。

## sort 與 uniq：把雜訊變成計數

面對幾萬行重複的文字，你真正想問的是：「哪一個出現最多？」答案是把兩把武器接起來：

```bash
cut -d" " -f6 access.log | sort | uniq -c | sort -rn | head
```

拆開來看：`cut` 取出每一行第 6 欄，`sort` 排序（讓相同的相鄰），`uniq -c` 統計每種出現幾次，`sort -rn` 依次數從大到小排，`head` 只看前十名。這條管線是流量分析、也幾乎是所有「計數題」的標準解法。

## cut 與 wc：取欄位、數行數

* `cut -d ":" -f1 /etc/passwd`：用 `:` 當分隔，取出第 1 欄——你立刻得到所有使用者名稱。
* `wc -l 檔案`：數一數有幾行。`wc -l` 也是「這份日誌有多大」的快速量尺。

`cut` 配 `-d`（分隔字元）與 `-f`（欄位），是處理冒號、逗號分隔資料的標準工具。

## history：你自己的命令日誌

Shell 會把你打過的指令記下來，用 `history` 查看，`!123` 重跑第 123 條。對你自己很方便，但這裡有個資安重點：

> 永遠不要在指令列上輸入密碼或金鑰。 history 檔案、shell 記錄、螢幕錄影、ps 的輸出——都可能把「看起來無害」的 mysql -p secret123 洩露出去。要輸入密碼，讓程式自己提示你，不要打進指令。這不是禮貌，這是把機密留在磁碟上的最常見方式之一。

`history` 配 `grep` 也很好用——比如確認自己剛才到底打過什麼跟下載有關的指令：

```bash
history | grep -iE "curl|wget"
```

這正是管線的威力：一個工具負責列，另一個負責濾。每一節的工具，都可以像樂高一樣互相拼接。

## 安全地讀檔案

大型檔案或日誌，直接 `cat` 會把整個螢幕淹沒。養成這些習慣：

| 目的 | 工具 |
|---|---|
| 慢慢翻閱 | `less 檔案`（空白鍵翻頁、`q` 離開） |
| 看開頭 | `head -20 檔案` |
| 看結尾（日誌最有用） | `tail -20 檔案` |
| 邊寫邊追蹤 | `tail -f 檔案`（follow 模式，新行自動出現） |

`less` 是「在文字裡散步」的首選，配 `/關鍵字` 可以原地搜尋。而 `tail -f` 是追蹤即時日誌的標準姿勢——log 有新的一行，畫面立刻跟上。

## 串成實際的一行指令

把上面的工具組合起來，資安工作最常出現的兩個問題。第一：這台機器現在開了哪些門？

```bash
ss -tlnp        # 有哪個服務在監聽哪個連接埠
```

`ss -tlnp`：`-t` TCP、`-l` 監聽中、`-n` 用數字顯示連接埠、`-p` 顯示程式。這一行會告訴你「這台機器現在對外開了哪些門」，是調查與加固的第一站。配合前面學的，你也可以問得更細：

```bash
ss -tlnp | grep -v "127.0.0.1"
```

把只綁在本機的服務濾掉，剩下的就是「對外可見」的服務——那才是真正的攻擊面。

## 這套工具箱的清單

| 工具 | 一句話記住它 |
|---|---|
| `\|` `>` `>>` | 輸出給誰吃、寫去哪 |
| `grep` | 在文字裡過濾 |
| `find` | 在檔案系統裡找檔案 |
| `sort` `uniq` `cut` `wc` | 排序、計數、切欄位、數行數 |
| `less` `head` `tail` | 安全地讀檔案 |
| `history` | 自己打過什麼 |
| `ss` | 誰在監聽哪個連接埠 |

這些工具沒有一個「高深」，但組合起來就是調查員的日常。`ps aux | grep` 讓你看見程序，`grep error /var/log` 讓你看見異常，`ss -tlnp` 讓你看見門面——**資安調查，多半就是這幾招的反覆。**

> 手感怎麼練？不需要背。每天處理問題時，把「我要找某個東西」的衝動，翻譯成 grep、find 或 ss 的問題。一週之後，這些工具就不再是知識，而是反射動作。
