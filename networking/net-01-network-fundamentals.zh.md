# TCP/IP、網段與埠

> 📅 2026-08-05 · 核心概念
> 你打開瀏覽器，網址打下去，一秒後頁面就出現。這中間到底發生什麼？理解資安之前，你得先看懂網路是怎麼把兩台電腦連在一起的——IP 位址、傳輸方式、還有那扇叫做「埠」的門。

---

你打開瀏覽器，網址列打上一個網站，一秒後頁面就出現。太自然了，以至於很少有人停下來問：**這中間到底發生什麼？**

要理解資安——為什麼某些攻擊有效、為什麼防火牆有用、為什麼開某個埠很危險——你得先看懂網路是怎麼把兩台電腦連起來的。好消息是，這個基礎沒有你想的複雜。把它想成「寄信」就可以了。

## 網路就是「寄信」

兩台電腦要溝通，跟兩個人寄信幾乎一樣。一封完整的信有三個要素：

* **收件地址**：住在哪一棟房子——對應到 **IP 位址**。
* **送達方式**：掛號還是平信——對應到 **TCP 或 UDP**。
* **收件部門**：寄到公司的哪個部門——對應到 **埠（port）**。

只要把這三件事搞清楚，網路的骨架就通了。而這三個概念，正好也是資安裡最常被提起的名詞。

## IP 位址：網路的門牌

每台連上網路的裝置都有一個 **IP 位址**，就像房子的門牌。目前最常見的是 **IPv4**，格式是四組數字，例如 `192.168.1.10`。位址空間更大的 **IPv6** 也在普及，但概念相同。

IP 位址還分「公有」與「私有」：

| 類型 | 用途 | 範例 |
|---|---|---|
| 公有 IP | 在網際網路上獨一無二、可被外界找到 | `8.8.8.8`、`104.18.12.5` |
| 私有 IP | 只在內部網路使用，外部無法直接連到 | `192.168.x.x`、`10.x.x.x` |
| 環回（loopback） | 指「這台電腦自己」 | `127.0.0.1` |

這條界線很重要：**你的家用路由器只有一個公有 IP，家裡的電腦全是私有 IP。** 外界的連線要先到路由器，再由路由器轉送——這層轉送，本身就是一道防火牆式的屏障。後面談到掃描與防火牆時，你會一再遇到「公有 vs 私有」這個分水嶺。

## TCP 與 UDP：兩種送信方式

有了地址，還要決定怎麼寄。網路世界有兩種主要方式：

* **TCP**：像掛號信。寄出前先確認對方在，每一封都有回執，掉了會重寄，而且順序不會亂。
* **UDP**：像廣播或平信。丟出去就不管了，快、但可能掉封包、也可能亂序。

| 特性 | TCP | UDP |
|---|---|---|
| 是否先建立連線 | 是 | 否 |
| 是否保證送達 | 是 | 否 |
| 速度 | 較慢 | 較快 |
| 典型用途 | 網頁、Email、SSH | 視訊、DNS 查詢、遊戲 |

一句話記住：**要準確、要可靠，用 TCP；要快、可以接受偶爾掉，用 UDP。**

## 埠：門牌上的門

一台伺服器同時提供很多服務——網頁、Email、遠端登入——全都共用同一個 IP。**埠（port）就是用來區分「同一台機器上的不同服務」**，像是一棟房子裡的不同部門。

每個服務通常有「預設埠」：

| 埠 | 服務 | 用途 |
|---|---|---|
| 22 | SSH | 安全的遠端登入 |
| 53 | DNS | 把網址翻譯成 IP |
| 80 | HTTP | 未加密的網頁 |
| 443 | HTTPS | 加密的網頁 |
| 3389 | RDP | Windows 遠端桌面 |
| 8080 | HTTP 替代 | 代理伺服器或測試用 |

對資安而言，**「哪個埠開著」就是「哪扇門沒鎖」的線索。** 一台機器如果把 SSH（22）開到整個網際網路、還用弱密碼，等於告訴全世界「歡迎來試」。這就是為什麼後面 `recon-03-scanning-nmap` 要掃描埠——不是為了亂搞，而是先知道自己開了哪些門，才知道要關哪些。

> 把 IP、埠、TCP/UDP 想成「地址、部門、寄法」三件套，之後每一篇網路相關文章都是從這裡長出來的。

## 網段與子網路

「網段」是把網路切成小組的方式，讓同一組內的機器可以直接互相溝通，跨組則要透過路由器。舉例：`192.168.1.0/24` 就是一個常見的網段，裡面可以放 `192.168.1.1` 到 `192.168.1.254`。

網段跟資安高度相關，因為**實體隔離是最簡單的防禦**：

* 辦公室電腦與對外伺服器放在不同網段，就算一端被打穿，另一端不會立刻失守。
* 家用路由器的「訪客網路」就是把陌生裝置隔到另一個網段。
* 雲端上的「子網路（subnet）」也是同一個概念，`secplus-04-security-architecture` 會深入談分區與隔離。

## 把這三件套用起來

現在你有能力回答一個很實際的問題：「我的電腦到底開了哪些門？」在 Linux 上，`linux-08-networking-cli` 教過用 `ss -tlnp` 去看。看到任何你沒在用的服務開著，那就是該關掉的門。

## 下一步

地址有了、門認識了，下一個問題自然浮現：**網址列那把「鎖」到底是怎麼鎖上的？** 這正是 `net-02-tls-https` 要拆解的。

#### Q: 一台伺服器同時提供網頁與 Email，怎麼區分這兩種服務？

* 用兩條不同的網路線

* 用不同的埠（例如 80 與 25）

* 用不同的 IP 位址

* 用不同的作業系統

> 💡 埠是用來在同一台機器的 IP 上區分不同服務的；網頁與 Email 各佔一個預設埠。
